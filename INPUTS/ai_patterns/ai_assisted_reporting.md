# AI-Assisted Reporting Pattern

## Purpose
Use AI to accelerate reporting, narrative generation, insight explanation, variance commentary, and performance interpretation.

## When to Use
Use this pattern when reporting is repetitive, manual, spreadsheet-heavy, fragmented across sources, or difficult for stakeholders to interpret.

## Typical Pain Points Addressed
- limited_real_time_insights
- data_fragmentation
- manual_reconciliation
- zombie_data
- excel_middleware
- duplicated_proceses

## Business Capabilities Supported
- management reporting
- financial planning and analysis
- performance management
- executive reporting
- compliance reporting
- transformation reporting
- operational analytics

## Technology Capabilities Required
- governed reporting layer
- semantic models
- BI integration
- natural language generation
- natural language querying
- data lineage
- report workflow approval

## Typical Use Cases
- executive report summaries
- variance explanations
- KPI commentary
- finance close narratives
- operational dashboard explanations
- natural language querying of data
- transformation status reporting

## Operating Model Impact
- shifts reporting teams from manual compilation to insight review
- requires metric ownership and source-of-truth governance
- improves stakeholder-specific communication
- reduces dependency on spreadsheet narratives
- introduces approval controls for published reports

## Data Requirements
- trusted metrics
- data definitions
- source-of-truth systems
- prior-period reports
- commentary rules
- stakeholder audience profiles
- evidence sources

## Integration Requirements
- Power BI
- Tableau
- SAP Analytics Cloud
- Snowflake
- Databricks
- ERP or EPM systems
- document generation tools
- approval workflows

## Governance and Risk Considerations
- never invent figures
- cite data sources
- separate fact from interpretation
- require owner approval for external or regulated reporting
- maintain metric definitions
- control access to sensitive reports
- ensure explainability of generated commentary

## Value Drivers
- reporting cycle time reduction
- better narrative consistency
- reduced manual consolidation
- improved stakeholder communication
- higher analyst productivity
- faster insight consumption

## Success Metrics
- reporting cycle time
- manual consolidation effort
- report rework rate
- commentary acceptance rate
- stakeholder satisfaction
- number of reports using governed sources
- reduction in spreadsheet dependencies

## Common Failure Modes
- weak data governance
- unclear metric definitions
- duplicated reporting logic
- unsupported AI-generated conclusions
- lack of approval workflow
- overproduction of narrative without insight
