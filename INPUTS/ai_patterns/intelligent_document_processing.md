# Intelligent Document Processing Pattern

## Purpose
Extract, classify, validate, summarize, and route information from documents to reduce manual handling and improve process quality.

## When to Use
Use this pattern when document-heavy workflows create delays, rekeying, quality issues, audit burden, or fragmented evidence.

- contract review

## Operating Model Impact
- shifts teams from manual extraction to exception review
- improves consistency of document handling
- requires document ownership and validation rules
- creates structured data from unstructured records
- strengthens evidence management

- access control
