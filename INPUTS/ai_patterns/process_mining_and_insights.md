# Process Mining and Insights Pattern

## Purpose
Use process data, logs, and AI-assisted analysis to discover how work actually flows and identify bottlenecks, variants, deviations, and automation opportunities.

## When to Use
Use this pattern when documented processes differ from reality, process ownership is fragmented, or transformation requires evidence of current-state execution.

## Governance and Risk Considerations
- validate event log quality
- protect personal and sensitive data
- avoid using process data to blame individuals
- document assumptions and filters
- require process owner validation
- treat insights as hypotheses until confirmed
