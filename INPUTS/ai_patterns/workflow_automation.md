# Workflow Automation Pattern

## Purpose
Use AI and automation to reduce manual effort, route work, trigger actions, standardize process execution, and manage exceptions.

## When to Use
Use this pattern when work is repetitive, rules-based, approval-heavy, delayed by handoffs, or dependent on manual status tracking.
